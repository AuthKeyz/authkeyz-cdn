# AuthKeyz CDN Assets

Static asset distribution repository for the AuthKeyz authentication and licensing platform.

## Contents
- `/v2/assets/`: Compiled styling, JavaScript vendor bundles, Datatables, and LineIcons.
- `/v2/panel/`: Customer and developer portal stylesheets and plugins.

## Deployment
Assets in this repository are served through the high-performance AuthKeyz content delivery network at `https://authkeyz.bond/assets/`.
